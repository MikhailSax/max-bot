# Простой бот для MAX + перевод в Открытые линии Битрикс24

Этот пример делает ровно нужный сценарий:
1. Бот здоровается.
2. Кратко рассказывает о компании.
3. Спрашивает, есть ли у клиента вопросы.
4. После следующего сообщения клиента передает диалог в Битрикс24 (Открытые линии), где менеджер продолжает общение.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

Сервис поднимется на `http://localhost:8080`.

## Входящий webhook

`POST /webhook/max`

Пример тела:

```json
{
  "chat_id": "123",
  "text": "Привет"
}
```

## Логика диалога

- Первое сообщение клиента → бот отправляет приветствие + описание компании + вопрос про вопросы.
- Второе сообщение клиента → бот отправляет «подключаю менеджера» и делает handoff в Битрикс24.
- Дальше сообщает, что диалог уже у менеджера.

## Переменные окружения для Битрикс24

- `BITRIX24_WEBHOOK_URL` — URL входящего вебхука Bitrix24 (`https://your.bitrix24.ru/rest/1/xxxx`).
- `BITRIX24_OPEN_LINE_ID` — ID открытой линии.
- `BITRIX24_MANAGER_ID` — (опционально) ID конкретного менеджера для перевода.

Если переменные не заданы, бот будет работать без фактического перевода (с предупреждением в логах).

## Проверка

```bash
curl -X POST http://localhost:8080/webhook/max \
  -H 'Content-Type: application/json' \
  -d '{"chat_id":"42","text":"Привет"}'
```
